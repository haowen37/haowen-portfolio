# HAOWEN personal identity

Two 2400 × 2400 presentation boards, composed with `scripts/render-identity-boards.ps1` on 2026-10-26.

- `01-logo.png` shows smaller primary and reversed versions of the owner's selected LHW artwork, without the earlier name lockup or Custom caption. The original bitmap is used twice; CSS inversion supplies the reversed presentation in `outputs/personal-brand-guide/logo-board.html`.
- `02-typeface.png` renders actual installed Neue Haas Unica W1G Regular glyph outlines and identifies Arial as the only fallback.

The homepage cover uses the original transparent circular logo from `../logos/lhw/lhw-original.png`, with the gallery's existing float/caption behaviour. The `#project/identity` route contains only these two boards, an accessible title and a return link. Detail images are static: no enlargement controls, zoom cursors or click actions. Homepage project navigation remains enabled.
