HAOWEN upright v2

Eight native upright SVG variants, plus eight heavier navigation copies.
The original v1 files are retained unchanged one directory above.

The unequal source axes are normalized onto an upright square grid.
Top nodes: y=80. Middle nodes: y=210. All four bottom nodes: y=340.
Connections and drawing animation timings are retained from v1.
Navigation stroke/node radius: 12/16. About: 5.2/9.6.
Dots have a larger proportional increase. No CSS rotation is needed.

Regenerate from v1 with scripts/create-upright-logos.py.
To return the site to v1, remove upright-v2/ from the logo paths in
dist/content.js and restore the original fallback/favicon paths in index.html.
